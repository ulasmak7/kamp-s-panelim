# Kampüs Panelim

Notlar, ödevler, sınavlar, ders programı, ortalama, devamsızlık, bilgi kartları, final hesabı ve bütçe — tek sayfada. Yüklenebilir uygulama (PWA) olarak çalışır.

## GitHub Pages'e yükleme
1. github.com'da yeni bir **public** repo aç (örn. `kampus-panelim`).
2. **Add file → Upload files** ile bu klasördeki dosyaların hepsini sürükle: `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`. **Commit changes**'e bas.
3. **Settings → Pages** bölümünde Source olarak **Deploy from a branch**, branch olarak **main** ve **/ (root)** seç, **Save**'e bas.
4. Bir iki dakika sonra adresin hazır: `https://KULLANICI_ADIN.github.io/kampus-panelim/`

## Telefona kurma
- **iPhone (Safari):** Paylaş → Ana Ekrana Ekle.
- **Android (Chrome):** ⋮ menüsü → Uygulamayı yükle.

## Veriler
Veriler cihazdaki tarayıcıda saklanır. Cihazlar arası taşımak için menüdeki **Yedek** sayfasını kullan: bir cihazda yedeği indir, diğerinde geri yükle. iPhone'da ana ekrana eklenen uygulamanın verisi Safari'den ayrıdır; uygulamayı ekledikten sonra yedeği içine yükle.

## Güncelleme
`index.html`'i değiştirip repoya yüklemen yeterli. Uygulama bir sonraki açılışta yeni sürümü alır.
